# SoliTea 🍵

Chào mừng bạn đến với **SoliTea** – thương hiệu trà sữa hướng đến sự tinh tế, hiện đại và trải nghiệm khách hàng tuyệt vời.

🌐 Truy cập website tại: [https://soliteavn.com](https://soliteavn.com)

## 📌 Giới thiệu

**SoliTea** là một chuỗi cửa hàng trà sữa với sứ mệnh mang đến những ly trà ngon, an toàn và đậm chất riêng.

## 🚀 Tính năng chính của trang web

- ✅ Giới thiệu thương hiệu và câu chuyện SoliTea
- 📋 Danh sách sản phẩm đặc trưng
- 📈 Thông tin chi phí – lợi nhuận nhượng quyền minh bạch
- 🛠 Quản lý sản phẩm và blog dành cho admin (đang hoàn thiện)
- 🧭 Quy trình nhượng quyền từng bước rõ ràng
- 📰 Blog cập nhật kiến thức ngành F&B (đang hoàn thiện)
- 📞 Thông tin liên hệ hỗ trợ nhanh chóng

## 📁 Công nghệ sử dụng

- **Frontend:** Vue.js + TypeScript + Tailwind CSS  
- **Backend:** .NET core
- **Hosting:** AWS
